# crescent.sys

```lua
local sys = require("crescent.sys")
```

| Name | What it is |
|---|---|
| [Notify](Notify.md) | Shows a line in the phone's notification shade. |
| [Service](Service.md) | Runs the project's background.lua with no screen, behind a notification. |
| [System](System.md) | System information and helpers. |
| [Task](Task.md) | Runs one of the project's script files off the screen's thread, in its own Lua world. |
| [Timer](Timer.md) | Calls a function every interval milliseconds while started. |
